# TwinCoach 本導入前チェックリスト

---

## 目的

- PoC後に本導入へ進める前の確認資料
- 技術・運用・権限・契約・セキュリティ・サポートの準備状況を確認する
- クリティカルな既存業務を止めず、**段階導入できる状態か判断する**

---

## 結論

- 本導入はPoC結果だけで判断しない
- 設計書・権限・データ・契約・運用・環境が整ってから進める
- hacomono / kintone を止めず、TwinCoach は段階的に導入する
- 高リスク機能は本導入後も別フェーズで検討する
- **Go / 条件付きGo / No Go の判断基準を持つ**

## Go / 条件付きGo / No Go 判断基準

| 判断 | 条件 | 次の対応 |
|---|---|---|
| **Go：本導入へ進める** | PoC結果OK、権限・データ・契約・環境・運用が整っている、段階導入計画がある | 本導入フェーズ1を開始する |
| **条件付きGo：条件を満たせば進める** | PoCはOKだが、契約・権限詳細・操作マニュアル・環境のいずれかが未整備 | 未整備項目を特定し、期限を設けて対応してから進める |
| **No Go：本導入を延期・再PoC** | 入力負担が許容できない、本部・オーナーが価値を感じなかった、権限設計が不十分、データ精度に問題がある | 課題を整理し、追加PoCまたは設計見直しを実施する |

---

## 本導入直後にやらないこと

- hacomono API本番連携を即開始しない
- kintoneを即廃止しない
- カルテ等のクリティカル機能を即置き換えない
- 顧客チャットを即導入しない
- FC精算を即本番運用しない
- 全店舗に一斉導入しない
