# TwinCoach ロール別本番チェックリスト

## 目的
リリース前に、本部・オーナー・店舗それぞれの閲覧範囲、導線、スマホ表示、データスコープが壊れていないか確認する。

---

## 1. 本部ロール

### ダッシュボード
- [ ] 本部ログインできる
- [ ] 本部ダッシュボードが表示される
- [ ] 本部用サイドバーが表示される
- [ ] 店舗ロール用のメニューに切り替わらない

### 店舗
- [ ] 店舗一覧に入れる
- [ ] URLが `/hq/stores` になっている
- [ ] 店舗詳細に入れる
- [ ] URLが `/hq/store/...` になっている
- [ ] 店舗詳細から戻っても本部文脈が維持される

### 会員・タスク
- [ ] 会員一覧が表示される
- [ ] タスク一覧が表示される
- [ ] 必要な全体データが見える

---

## 2. オーナーロール

### ダッシュボード
- [ ] オーナーログインできる
- [ ] オーナーダッシュボードが表示される
- [ ] オーナー用サイドバーが表示される
- [ ] 本部専用メニューが見えない

### 店舗
- [ ] 店舗一覧に入れる
- [ ] URLが `/owner/stores` になっている
- [ ] 店舗詳細に入れる
- [ ] URLが `/owner/store/...` になっている
- [ ] 店舗詳細から戻ってもオーナー文脈が維持される

### 会員・タスク
- [ ] 会員一覧が表示される
- [ ] タスク一覧が表示される
- [ ] オーナー向けに必要なデータが見える

---

## 3. 店舗ロール

### 基本表示
- [ ] 店舗ログインできる
- [ ] 店舗用サイドバーが表示される
- [ ] 本部メニューが見えない
- [ ] オーナーメニューが見えない
- [ ] 全店舗一覧が見えない

### 会員
- [ ] `/members` に入れる
- [ ] 自店舗会員だけ表示される
- [ ] 他店舗会員が表示されない

### タスク
- [ ] `/tasks` に入れる
- [ ] 自店舗会員に紐づくタスクだけ表示される
- [ ] 他店舗タスクが表示されない

### セッション入力
- [ ] `/session-input` に入れる
- [ ] 会員選択が自店舗会員だけになっている
- [ ] セッション入力がスマホでも表示される
- [ ] 入力画面が崩れていない

### アクセス制御
- [ ] `/stores` に直接アクセスするとリダイレクトされる
- [ ] `/hq` に直接アクセスできない
- [ ] `/owner` に直接アクセスできない

---
