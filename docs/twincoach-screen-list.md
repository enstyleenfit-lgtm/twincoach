# TwinCoach 画面一覧

作成日：2026-06-06  
対象バージョン：PoC（現行実装）

---

## 結論

- 画面は **本部（HQ）/ オーナー / 店舗 / トレーナー / 共通** の5区分に整理できる
- PoCでは全画面を使うのではなく、**会員継続率・LTV・店舗運営の価値検証に直結する画面**を優先する
- 本導入前に、画面項目一覧・CRUD・権限仕様へ展開する

## PoCでは優先度を下げる画面

補助機能・将来候補として位置づけ、PoC期間中は積極活用しない。

| 画面名 | 理由 |
|--------|------|
| 在庫管理（本部・オーナー・店舗） | 収益改善の価値検証と直接関係しない |
| 応援掲示板（本部・オーナー・店舗） | 運用フローが固まっていないと効果測定が難しい |
| 売上管理（本部・オーナー） | 未払い管理など未実装機能含む。PoCでは来月損失予測で代替 |
| トレーナー一覧・分析 | トレーナーごとの継続率は参考値として確認。分析の深堀りは本導入後 |
| 設定内のCSV/API連携詳細 | 初期設定が完了すれば日常利用には不要 |
| レポート（本部・オーナー） | ダッシュボードで代替可能。詳細レポートは本導入後に整備 |
| トレーナーダッシュボード（`/trainer`） | 店舗ロールで代替可能。PoC段階ではロール整理を優先 |
| 顧客チャット・FC精算 | 未実装機能。本導入後の検討事項 |
